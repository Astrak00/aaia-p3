AUGMENTATION CHANGES vs Round 4:
  Old train_transform:
    Resize(256) → RandomCrop(224) → HFlip(0.5) → VFlip(0.5) → Rotation(30°)
    → ColorJitter(b=0.3,c=0.3,s=0.2,h=0.05) → ToTensor → Normalize → RandomErasing(0.1)
  New train_transform (R5):
    RandomResizedCrop(224, scale=(0.7,1.0), LANCZOS) → HFlip(0.5) → VFlip(0.5)
    → Rotation(180°) → ColorJitter(b=0.3,c=0.4,s=0.3,h=0.05)
    → GaussianBlur(k=5,sigma=(0.1,1.5), p=0.3) → ToTensor → Normalize → RandomErasing(0.1)
  Rationale for changes:
    - RandomResizedCrop replaces Resize+RandomCrop for better scale invariance
    - Rotation 30°→180°: fundus images are rotationally invariant (no canonical up)
    - Stronger color jitter (contrast 0.3→0.4, saturation 0.2→0.3): camera/lighting variation
    - GaussianBlur(p=0.3): simulate focus/blur artifacts common in fundus photography
    - Removed Resize(256) since images are already 512×512
